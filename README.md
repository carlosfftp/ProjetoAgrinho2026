# ProjetoAgrinho2026
Este site foi desenvolvido como parte do Projeto Agrinho, com o obigetivo de apresentar a inportancia e as carecteristica do agro no sudoeste do parana, destacando a agricultura, a sustabilidade, a preservação anbiental e as tecnologia utilisadas no canpo de forma criativa e interativa.

O projeto também serve como preática de programação web utilizando linguagem HTML, CSS e JavaScript.

# Funcionalidades
- Layout moderno e responsivo;
- Galeria de imagems do agro;
- Cards imformativos;
- Navegação suave;
- Menu de acessibilidade;
- Efeitos visuais;
- Quiz interativo.
